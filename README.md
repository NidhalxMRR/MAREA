# MAREA
**Marine Aquaculture Risk & Early-warning Analytics**

**Predict the water. Protect the harvest.**

MAREA is an environmental monitoring and early-warning platform for marine aquaculture. It helps track water conditions, visualize historical readings, and prepare for thermal stress events before they affect fish or shellfish production.

## Current MVP capabilities
- water-quality dashboard
- sea-water temperature monitoring
- CSV/XLSX historical-data import
- configurable environmental thresholds
- alerts and anomaly detection
- historical charts
- simulated sensor readings for development

## Upcoming development
- real ESP/LoRa sensor ingestion
- persistent backend and database
- live sea-temperature telemetry
- time-series forecasting and predictive alerts
- additional environmental sensors such as salinity, pH, dissolved oxygen, and turbidity

## Run locally

Prerequisites: Node.js and npm

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`
3. Build for production:
   `npm run build`

MAREA is currently under active development as an IoT + AI aquaculture early-warning platform.
